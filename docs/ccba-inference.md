# 新睿 CCBA 叫牌约束联动

## 依据

用户指定官网现行“新睿二盖一（CCBA）”，明确排除“简易二盖一”。2026-09-08 从[新睿官网](https://d.xinruibridge.com/)体系说明链接下载 [ccba_word_v2.2.zip](https://oss.xinruibridge.com/doc/ccba_word_v2.2.zip)。文档标识为《CCBA 体系说明》版本 2.2，北京新睿桥科技有限公司，2019.10。ZIP 的 SHA-256 为 `CB2684E275E7BB9CE9CE9395C536A7FBF25F84EC03B6C240C9E9AE448712E1FC`。

没有使用另列的 `nbs_word_v1.0.4.zip`（简易二盖一），也没有沿用官网较旧 HTML 的 CCBA 2.1。实现为自行编写的规则映射；原文档不随站点发布。

## 交互与数据

点选、粘贴、编辑、撤销和清空都会从当前完整叫牌串重新推断，不累积旧约束。支持花色符号、中文“不叫”、PASS 和 1N 简写。非法叫牌显示错误并禁用分析，不沿用之前合法串的推断。

未手动修改的字段跟随体系更新；手动修改的点力、单门长度、表达式分别覆盖对应自动字段。修改一门长度不会冻结另外三门。每家显示来源，可恢复本家或全部自动推断，也可显式设为不限。暂不反向根据手动点力猜测/改写叫牌，也不根据输入叫牌改动原牌局的定约。

“叫牌解释与规则来源”列出叫品的方位、序号、上下文含义与体系章节；只对有明确约定意义的 PASS 推断（如转移被加倍后不叫、低花迫转后的止叫），不从一般不叫猜测点力。未覆盖项单独提示。最终有效约束沿用既有采样器，不修改原牌例或首攻以外的实际手牌数据。

当前牌局的局况自动传入推断器，按叫牌人的实际阵营判断有局/无局。伯根 3D、无局跳加叫、对强无将双低争叫及对无将争叫的反击使用相应的局况分支，不增加另一个易与牌局不一致的局况开关。

## 实际参与采样的复杂条件

`lead-constraints.ts` 支持括号内的 AND / OR 分支、`aces`、`keys <trump>`、`controls`（A=2、K=1）和指定牌集合的计数。原有逗号 AND 与简单 OR 语法兼容。以下不是仅展示的叫牌注释：

- 反加叫 / 1D–2C 后 2NT 的 `12–14 或 18–19` 不会接受中间的 15–17 点。
- 被加倍后一高花的好加叫/弱加叫，保留三张支持与四张支持各自的点力分支。
- 逆朱瑞、杰可贝和 Mini-Splinter 的控制/短门条件进入筛选。
- 关键张答叫按四个 A 加将 K 计数，将 Q 另算；缺门问叫剔除缺门 A。
- 赌博性 3NT 要求七至八张 AKQ 低花，并检查边花无 A/K、至多一个 Q。

点力/长度输入框显示简单范围，不能用单一区间表达的联合含义显示在“高级条件”。手动改范围不会自动删掉高级条件，需分别修改或恢复本家推断。

## 近似和未覆盖部分

这是 CCBA 约定到发牌条件的映射，不是对生成牌逐副重放叫牌的完整叫牌机器人。可量化的联合分支已进入筛选；以下仍是实现边界，不用“已识别”冒充精确复现全文：

- 1NT 允许五张高花、六张低花和部分 5422，不再强制通用 `balanced`；当前只加各花色上界，可能接受体系不允许的其他形状。
- 弱二长套允许降点；第三家轻开不硬定点力下限。强二只取各强牌分支的共同 HCP 下限，赢墩与速胜墩条件未实现。
- 含“好/差”或不同点力/配合分支的范围用外包区间；伯根 3D 的 9–12 包含 §2.6 的无局分支。调整点不转换成大牌点。
- 自然争叫按通常五张建模，特殊四张争叫可手动放宽。双套叫的套质量、“好/差”点数、止张、二三法则、赢墩来源等仍有仅解释而未硬筛的含义。
- 原文正文与附录有差异时优先正文；低花开叫被加倍后 1NT 的 7–10 / 8–11 差异在解释中明确保留并集。没有把旧附录数值静默混入正文。
- 多轮四家竞争、所有扣叫否认顺序、任意长程再叫尚非完整穷举；无法唯一确认将牌或存在示量歧义时，不硬套 RKCB。5NT 对联手关键张齐全的承诺目前保留说明，不错误地要求叫牌者个人持全。
- 按 CCBA 解释所输入双方叫牌，尚无敌方精确制/弱无将等独立体系选择。不将所有不叫视为“不能开叫/应叫”的反向排除条件。

推断出的自动字段可手动改写；覆盖不全会在页面提示，不宣称完整体系一致。
