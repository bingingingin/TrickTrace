# 首攻约束对照与边界（2026-09-08）

参考：https://killerbridgeleads.com/，本次直接读取站点的约束说明和模拟控制代码。

| 能力 | 原实现 | 本轮 |
| --- | --- | --- |
| 各家点力、花色长度 | 手写 JSON | 按庄家、明手、同伴分别编辑，有范围和 13 张一致性校验 |
| 牌型 | 无 | 均型、无序 shape、多候选牌型及按 SHDC 顺序的精确牌型 |
| 牌张和花色点力 | 无 | 必须持有大牌、排除大牌、花色 HCP |
| 组合条件 | 无 | 逗号 AND、单段 OR；不支持任意括号嵌套 |
| 联手点力 | 无 | 庄家与明手合计 HCP 范围 |
| 叫牌填充 | 无 | 导入已有叫牌；可手动编辑，首次自然开叫模板，明确说明未解释的叫牌 |
| 叫牌引擎重放 | 无 | 仍未接入；参考站使用 EPBot/BBA，本项目没有该引擎及使用授权，不把开叫模板称为等价实现 |
| 默认次数 | 128 | 首攻默认 1000，250/1000/2500/5000，允许自定义 16–5000 |
| 采样失败 | 无清晰提示 | 展示尝试次数、有效样本数和未达到目标提示 |
| 退出首攻副本 | 只隐藏页签 | 自动返回源牌局及其原有播放分支，兼容上一版同名副本 |

模板假设自然制、五张高花、1NT 15–17、2NT 20–21。不根据不叫自动设点力上限，不自动解释应叫、争叫、再叫或约定叫。自动填充会替换当前约束，按钮明确标出；用户须核对体系并补充。此处属于受约束的首攻模拟，尚不能宣称与参考站完整叫牌验证功能对等。

在击败率 50% 附近，Wilson 95% 区间半宽约为：128 次 8.5 个百分点，1000 次 3.1，5000 次 1.4。此区间只量化抽样误差，不覆盖叫牌模型错误和 DDS 全知假设的偏差。
