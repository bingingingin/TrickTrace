# 条件模拟与首攻分析

首攻与两家牌分析共用叫牌和手牌约束。首攻仅保留首攻方手牌，在 Worker 中生成满足条件的其余发牌；两家牌保留庄家与明手。模拟不新增牌例、不改写原始发牌或播放分支。

## 输入条件

- 各家大牌点与花色长度，例如 `15-17`、`5+`。
- 均型、无序牌型、按 SHDC 顺序的精确牌型。
- 指定持牌、排除牌、花色点力及庄明联手点力。
- AND / OR 与括号组合条件，以及 A、关键张和控制计数。
- 根据 CCBA v2.2 叫牌推断部分条件，支持逐字段手动覆盖和恢复。详见 [规则来源与覆盖](ccba-inference.md)。

叫牌草稿和手动覆盖按牌例隔离，在两种分析模式间共享；草稿仅在当前页面会话保存。非法叫牌会禁用分析，未覆盖的进程会提示。

## 模拟与结果

首攻默认采样 1000 次，支持 16–5000 次。快速模式只判断定约击败率；精确模式另外计算平均墩数。Worker 池按设备资源分批求解，可取消任务；采样不足时展示有效样本和尝试次数。

长度和历史缺门条件通过加权构造分布处理；点力、均型及高级表达式继续筛选。随机种子用于重现采样，但结果依赖所选约束与样本数。

## 边界

叫牌约束是部分规则映射，没有对每副样本执行完整叫牌引擎重放。DDS 对每副样本使用全知后续，两家牌与首攻结果仍有策略融合误差。抽样区间只描述抽样不确定性，不覆盖叫牌模型错误或全知假设偏差。

界面和输入设计参考过 [Killer Bridge Leads](https://killerbridgeleads.com/) 的公开功能；本项目的具体实现和边界以源码及测试为准。测试入口见 [验证说明](validation/status.md)。
