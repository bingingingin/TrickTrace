# 首攻约束对照与边界（2026-09-08）

参考：https://killerbridgeleads.com/，本次直接读取站点的约束说明和模拟控制代码。

模板假设自然制、五张高花、1NT 15–17、2NT 20–21。不根据不叫自动设点力上限，不自动解释应叫、争叫、再叫或约定叫。自动填充会替换当前约束，按钮明确标出；用户须核对体系并补充。此处属于受约束的首攻模拟，尚不能宣称与参考站完整叫牌验证功能对等。

在击败率 50% 附近，Wilson 95% 区间半宽约为：128 次 8.5 个百分点，1000 次 3.1，5000 次 1.4。此区间只量化抽样误差，不覆盖叫牌模型错误和 DDS 全知假设的偏差。

## 批量模拟与输入优化

- 首攻专用 Worker 池按设备核心数/内存分配 1–8 个线程，动态领取 8 副一批；关闭、取消、超时和错误会终止池内全部线程。先统一按种子生成分布，避免线程调度改变样本。
- 快速模式使用 DDS `target = 14 - (level + 6)`、`solutions = 2`，只判断防守方能否赢得足够墩数击败定约；精确模式继续使用 `target = -1`、`solutions = 3`。快速模式平均墩数为空，禁止平均墩数排序，不用阈值冒充精确值。
- 花色长度/历史缺门使用动态规划计数构造分布，按多项式组合数加权，保持满足这些条件的牌局均匀抽样。点力、均型、联手点力及高级表达式仍做拒绝筛选；只在接受候选后复制完整局面。不是对参考站完整 DP / 叫牌验证实现的复制。
- 叫牌加入合法叫品按钮、四方记录、撤销与粘贴；条件改为方位切换和单框范围，常用牌型中文按钮，高级条件折叠。模板仍只解释首次自然开叫，不改变定约。
- 本机 Chrome 生产构建、默认示例、种子 20260905、庄家 15–17 均型、1000 有效分布：快速 2.404 秒（采样 0.1 / 求解 2.3），精确 14.654 秒（采样 0.1 / 求解 14.5），均为 8 Worker。此前同一流程串行精确为 128.825 秒。单次测试不能代表所有牌局、设备或与参考站的配对测速。
- 验证：48 项测试通过，包括 10 副牌例跨花色/方位和 4 个定约阶数的阈值/精确首攻集合一致、加权采样小空间分布检查、约束与种子重现、批次汇总顺序无关、取消后旧结果隔离。两种模式的 1000 次浏览器流程均通过，包含输入校验、移动端不溢出、关闭后原牌局继续出牌。
- 线上 `https://tricktrace.pages.dev/` 验证同一流程 1000 次：快速 3.915 秒、精确 16.690 秒，页面错误为零。该性能版本对应提交 `94e8f62`，部署 `https://7fef50e3.tricktrace.pages.dev`。后续牌例管理补丁未改变求解器。
