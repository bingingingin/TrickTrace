## 处理原则

- 文字 Q 用另一种行分割方式交叉确认；整行字框与高置信度独立组件核对，恢复被合并的 8，并纠正 8→3。
- 平铺牌列遇到大间隔时，先检查间隔内是否仍有可见牌点，避免因漏花色而截掉后续牌；花色边界结合实际红色像素辨别。
- 扇形牌不允许中等置信度 OCR 随意覆盖极高置信度模型结果，例如把 6 改为 J。较弱的梅花候选还需满足高置信度黑色牌点、黑色像素、对称性及既有牌角几何约束。
- 对旋转定约重试时只保留深紫色文字，抑制背景与边框；需读到完整定约，不把一个数字补成 NT。
- 保留未知牌与核对提示，不按缺牌清单补牌。
